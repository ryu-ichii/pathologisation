# Pathologisation
Current working version of Ass 3 eLiterature work for RMIT Digital Writing, 2026. 

## Description
**Pathologisation** — psychosis, insatiability and uncertainty within the structures and routines of modernity. A simulation of a relentless mess of noise and impossibility, where reality crumbles under the weight of the mind. Pathologisation attempts to systemise the absurd and the arbitrary — it looks for meaning where there is none.

Aided by the added increased possibility and insatiability of computerisation, Pathologisation uses repetition and randomisation to extract patterns and structures from fragments of prose and poetry. By generating well over 350 million distinct reading experiences, no two interactions with the work should ever be the same. 

### References
- Claude [Large Language Model] (Anthropic, 2025) has been carefully used to edit and construct code that functions in TWINE Harlowe. It has not been used in any stage of the creative generation process. Claude has been harnessed to work purely within the margins of code to provide improvements and suggestions for aesthetics and functionality. 

## Content warning
Contains drug use, violence, suicidal themes and depictions of psychosis. Contains flashing images and rapid flicker.
